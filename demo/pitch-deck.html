What Makes This Different

Key Innovations

🔒

Placeholder Ref System

Server plans with [EMAIL_1], [PERSON_1] — real values resolved only in page-local map. LLM never sees actual data.

👁

Vision-First Redaction

BlazeFace reads the RAW frame first, deciding extra redaction regions — catching faces in images DOM cannot see.

🧠

8-Layer Defense

Regex + NER + ViT + BlazeFace + OCR + Injection Guard + Server Guard + DOM Context — depth no competitor matches.

📡

Offscreen Architecture

Chrome MV3 limitation solved: hidden document runs MediaPipe + tesseract with watchdog timeouts at every hop.

🚀

Self-Hosted Models

ViT (88MB ONNX), BlazeFace, Tesseract — zero external downloads at runtime. Works offline after first load.

🛡

Dual Injection Guard

9 regex patterns + hidden char stripping — mirrored client-side AND server-side before LLM sees any payload.
